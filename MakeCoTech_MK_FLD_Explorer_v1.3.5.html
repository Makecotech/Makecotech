How to read the FLD. A material point below the selected M–K FLC has not yet reached the modelled localized-necking limit. Reaching/crossing the curve means the M–K localization condition has been met for that proportional strain path. The blue wrinkle region is a separate reduced-order compression indicator and is not part of M–K.
Which M–K criterion is actually used? The yellow current curve uses the Eyckens-type numerical criterion used by this solver: |D₃₃ᵇ| / |D₃₃ᵃ| ≥ Clocwith default Cloc=10, or loss of a solution to the groove equilibrium problem. The violet 1967-style comparison curve fixes φ₀=0° to reproduce the original groove-orientation assumption, but deliberately uses the same modern detector so only the groove-orientation assumption changes.

How one M–K point becomes the FLC

This animation shows the inner M–K calculation used to create one FLD point. For a chosen matrix strain ratio ρ₂₂, many initial groove orientations φ₀ are tested. The orientation that localizes at the lowest matrix major strain is the critical groove; its matrix strains at localization become one point of the FLC.
What is ρ₂₂?ρ₂₂ = D₂₂ᵃ / D₁₁ᵃ = dε₂ᵃ / dε₁ᵃIt is the imposed in-plane strain-rate ratio of the homogeneous matrix a. For a monotonic proportional path, one number defines the direction of the strain path while D₁₁ᵃ only sets its rate/scale. For isotropic von Mises plasticity, useful landmarks are −0.5 = uniaxial-tension strain path, 0 = plane strain, and 1 = equibiaxial stretching. With Hill48, the strain ratio produced by a uniaxial stress test depends on the r-values and material orientation.

φ₀ is scanned to find the earliest localization for the chosen ρ₂₂. The current φ changes during deformation; it is not held equal to φ₀. The matrix strains at that earliest localization are stored as one FLC point.
Original M–K (1967): physical instability criterion. The original paper describes loss of stability as progressive strain concentration in the thinner groove, while deformation in the adjacent uniform sheet progressively fades; the limiting surrounding-sheet strain is the forming limit ε*. It does not introduce the later universal “10× thickness-strain-rate” threshold used below.
Numerical M–K criterion used by this tool / Eyckens formulation.|D₃₃ᵇ| / |D₃₃ᵃ| ≥ ClocThe Eyckens paper uses Cloc = 10 and a second criterion: localization is also declared if the nonlinear groove equilibrium/compatibility problem no longer has an acceptable solution. The paper notes that the precise large number has little influence because the groove thinning rate rises extremely rapidly near incipient localization. The editable “M–K localization ratio” is Cloc.
Abaqus M–K style criterion — for comparison. Abaqus/Explicit can monitor groove-to-nominal deformation-severity ratios for equivalent plastic deformation, normal deformation, and tangential deformation; the default critical severity factors are 10. Setting all severity factors to zero makes the Abaqus M–K check rely on nonconvergence of the equilibrium/compatibility equations. This tool currently uses the Eyckens thickness-strain-rate detector above, not the full Abaqus three-severity implementation.

Original 1967-style versus later full-FLD construction. The original M–K concept assumed an initially thinner, infinitely long groove oriented along the minor-strain direction and used the onset of strain localization / loss of stability to identify the limiting surrounding-sheet strain. Later full-FLD M–K formulations scan possible initial groove orientations and retain the lowest major strain at localization. In the comparison curve above, the original geometry/orientation assumption is isolated by fixing φ₀=0°; the same modern 10×/equilibrium detector is deliberately retained for both curves. Therefore the violet line is a controlled 1967-style calculation, not the historical published 1967 FLC itself.
Reference basis. The conventional M–K formulation and AA3003 validation parameters follow Eyckens, Van Bael & Van Houtte (2009), which revisits the conventional model and uses f₀=0.998, K=184 MPa, ε₀=0.00196 and n=0.224 for AA3003. The historical comparison is labelled “1967-style” because it fixes the groove orientation assumption while retaining the same modern numerical localization detector; it is not a digitized copy of the 1967 curve.
