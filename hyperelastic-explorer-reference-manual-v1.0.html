1 · Scope

Purpose and document control

This manual documents the equations and numerical procedures implemented in MakeCoTech Hyperelastic Explorer v1.0. Its purpose is to make the browser implementation auditable rather than a black box. The equations below describe the released tool behavior, including deliberate reductions and numerical safeguards.

ToolMakeCoTech Hyperelastic Explorer
Tool version1.0
Manual revision1.0
Reference year2026

Recommended reference:

MakeCoTech Hyperelastic Explorer v1.0, Technical Reference Manual Rev 1.0, MakeCoTech, 2026.

Scope boundary. This manual describes the MakeCoTech browser implementation, not the complete Abaqus material library. Several models are intentionally restricted to one order, homogeneous material-point loading, or a specific fitting strategy. These reductions are stated explicitly.

2 · Common assumptions

Units, conventions and modeling scope

Unless a section states otherwise, the tool assumes homogeneous, isotropic, isothermal, rate-independent and purely elastic/hyperelastic response. No finite-element mesh is solved.

QuantityConvention
StressMPa
Strain-energy densityMJ/m³; numerically 1 MPa = 1 MJ/m³
Stretchλ = current length / reference length
Engineering strainε = λ − 1
Volume ratioJ = det(F) = V/V₀
Volumetric pressurePositive in compression: J < 1 gives p > 0
Normal stress fitted internallyNominal / first-Piola stress
Simple shearShear amount γ with F₁₂ = γ

The released v1.0 tool does not represent rate dependence, Mullins effect, permanent set, viscoelasticity, plasticity, anisotropy, temperature-dependent coefficients, damage, cavitation or solver-level constitutive stability.

3 · Continuum kinematics

Principal stretches, invariants and stress measures

For principal stretches λ₁, λ₂ and λ₃:

J = λ₁ λ₂ λ₃.

The first two stretch invariants are

I₁ = λ₁² + λ₂² + λ₃²
I₂ = λ₁²λ₂² + λ₂²λ₃² + λ₃²λ₁².

For standard compressible hyperelastic models, the isochoric stretches and invariants are

λ̄ᵢ = J−1/3λᵢ
Ī₁ = J−2/3I₁
Ī₂ = J−4/3I₂.

Nominal stress versus Cauchy stress

P = J σ F−T.

For a diagonal principal deformation:

Pᵢ = J σᵢ / λᵢ.

For J = 1:

Pᵢ = σᵢ / λᵢ.

This last relation is used when incompressible Cauchy/true stress data are entered. In a compressible normal test, Cauchy stress alone does not determine nominal stress because J or the lateral stretches are also required. Therefore compressible normal-data fitting accepts nominal/engineering stress.

4 · Homogeneous loading modes

Kinematic reductions used by the tool

Incompressible uniaxial

λ₁ = λ,   λ₂ = λ₃ = λ−1/2,   J = 1.

Incompressible equibiaxial

λ₁ = λ₂ = λ,   λ₃ = λ−2,   J = 1.

Incompressible planar tension / pure shear

λ₁ = λ,   λ₂ = 1,   λ₃ = λ−1,   J = 1.

Simple shear

F = [[1, γ, 0], [0, 1, 0], [0, 0, 1]],   J = 1.

The non-trivial principal stretches can be written as

η = asinh(γ/2),   λ+ = eη,   λ− = e−η,   λ₃ = 1.

Planar/pure shear is not simple shear. The two modes follow different deformation paths and provide different constitutive information.

5 · Energy formulation

Stress from strain energy without an FEA solve

For a hyperelastic solid, stress is obtained from derivatives of the strain-energy density. Along a homogeneous one-parameter path, the work-conjugate nominal stress is obtained by differentiating the path energy.

Uniaxial and planar

P = dW*/dλ.

Equibiaxial

dW*/dλ = P₁(dλ₁/dλ) + P₂(dλ₂/dλ) = P₁ + P₂. For equal biaxial loading P₁ = P₂ = P: P = 1/2 dW*/dλ.

Simple shear

τ = dW/dγ.

Compressible free-surface equilibrium

For standard compressible uniaxial loading the tool writes λ₂ = λ₃ = t and minimizes

W(λ,t,t)

with respect to t. Since

dW/dt = P₂ + P₃ = 2P_transverse,

a stationary minimum gives zero transverse nominal traction. Equibiaxial and planar modes have one free thickness stretch, and the same stationarity condition gives P₃ = 0.

Once the free transverse state has been found, the axial stress is calculated by differentiating the minimized energy. The transverse derivative vanishes at equilibrium, so this is an application of the envelope theorem.

6 · Reference curve

Linear elastic — small-strain reference

The linear model is deliberately included only as a small-strain comparison. It is not presented as a finite-strain hyperelastic constitutive law.

For a compressible small-strain reference, ν is reconstructed from E and K₀:

ν = (3K₀ − E)/(6K₀).

and

G = E/[2(1+ν)].
ModeDisplayed stressDisplayed energy
UniaxialP = E(λ−1)W = 1/2 E(λ−1)²
EquibiaxialP = E/(1−ν)(λ−1)W = E/(1−ν)(λ−1)²
PlanarP = E/(1−ν²)(λ−1)W = 1/2 E/(1−ν²)(λ−1)²
Simple shearτ = GγW = 1/2 Gγ²

For fitting in the incompressible comparison mode, ν = 0.5, so the model basis functions become E(λ−1), 2E(λ−1), 4E(λ−1)/3 and Eγ/3 for uniaxial, biaxial, planar and shear respectively.

Large-strain extrapolation of the linear curve is intentionally educational only.

8 · Hyperelastic law

Mooney-Rivlin

Wiso = C₁₀(Ī₁−3) + C₀₁(Ī₂−3).
G₀ = 2(C₁₀+C₀₁).
ModeClosed-form incompressible stress
UniaxialP = 2C₁₀(λ−λ−2) + 2C₀₁(1−λ−3)
EquibiaxialP = 2C₁₀(λ−λ−5) + 2C₀₁(λ³−λ−3)
PlanarP = 2(C₁₀+C₀₁)(λ−λ−3)
Simple shearτ = 2(C₁₀+C₀₁)γ

Identifiability in simple shear

I₁ = I₂ = 3 + γ²
W = (C₁₀+C₀₁)γ².

Only the sum C10+C01 is identifiable from simple shear. Planar loading also collapses to the same sum because I₁ = I₂ = λ²+1+λ−2. The tool therefore warns that uniaxial and/or equibiaxial information is required if C10 and C01 are to be separated.

9 · Hyperelastic law

Ogden, N = 1, Abaqus-style normalization

Wiso = (2μ/α²)(λ̄₁α + λ̄₂α + λ̄₃α − 3).

Under this normalization:

G₀ = μ,   E₀ = 3μ for J = 1.

This differs from other Ogden conventions that place a different factor in front of the power sum. Therefore a parameter named μ from another convention is not necessarily numerically interchangeable.

ModeClosed-form incompressible stress
UniaxialP = (2μ/α)[λα−1−λ−α/2−1]
EquibiaxialP = (2μ/α)[λα−1−λ−2α−1]
PlanarP = (2μ/α)[λα−1−λ−α−1]

Simple shear derivation

η = asinh(γ/2) λ+ = exp(η), λ− = exp(−η), λ3 = 1 W = (2μ/α²)[exp(αη)+exp(−αη)−2] = (4μ/α²)[cosh(αη)−1] dη/dγ = 1/sqrt(4+γ²) τ = dW/dγ = (4μ/α)sinh(αη)/sqrt(4+γ²).

The GUI allows −20 ≤ α ≤ 20 and keeps |α| away from zero. The fitter accepts |α| ≥ 0.15.

10 · Polynomial laws

Yeoh and Reduced Polynomial N = 2

Yeoh

W = C₁₀X + C₂₀X² + C₃₀X³,   X = Ī₁−3.

Reduced Polynomial N = 2

W = C₁₀X + C₂₀X².

For the supported incompressible modes, define X and A as:

ModeX = Ī₁−3A
Uniaxialλ² + 2/λ − 3λ − λ−2
Equibiaxial2λ² + λ−4 − 3λ − λ−5
Planarλ² + 1 + λ−2 − 3λ − λ−3
Simple shearγ²γ

Then for Yeoh:

P = 2A[C₁₀ + 2C₂₀X + 3C₃₀X²].

For Reduced Polynomial N=2, the C30 term is omitted. These stresses are linear in the fitted coefficients, allowing an exact weighted linear least-squares solve.

G₀ = 2C₁₀.
11 · Network model

Arruda-Boyce fifth-order series

The implemented isochoric potential is the fifth-order series

W = μ [ 1/2(Ī₁−3) + (Ī₁²−9)/(20λm²) + 11(Ī₁³−27)/(1050λm⁴) + 19(Ī₁⁴−81)/(7000λm⁶) + 519(Ī₁⁵−243)/(673750λm⁸) ].

Differentiating near the undeformed state gives the initial shear modulus:

G₀ = μ[1 + 3/(5λm²) + 99/(175λm⁴) + 513/(875λm⁶) + 42039/(67375λm⁸)].

Therefore the Arruda-Boyce parameter μ is not exactly G0 for finite λm. The tool’s “Match Initial Stiffness” operation uses the inverse of this correction factor.

Displayed stresses are obtained by differentiating the path energy numerically. During fitting, μ is profiled analytically for each trial λm because the model response is linear in μ when λm is fixed.

Applied simplification: v1.0 uses the fifth-order invariant series shown above; it does not evaluate an exact inverse-Langevin function.

12 · Network model

Van der Waals / Kilian

Ĩ = (1−β)Ī₁ + βĪ₂
η = sqrt[(Ĩ−3)/(λm²−3)]

Wiso = μ{ −(λm²−3)[ln(1−η)+η] − (2/3)a[(Ĩ−3)/2]^(3/2) }.

The locking singularity occurs as η approaches 1. The implementation returns a numerical barrier when η ≥ 0.999999.

To prevent tiny negative values caused by floating-point noise, the implementation evaluates z = max(0, Ĩ−3) before calculating η and the 3/2 power.

The optimizer uses μ > 0, λm > √3, 0 ≤ β ≤ 1. In the released fitting algorithm the interaction parameter is mapped to approximately −0.95 < a < 0.95. This is an optimization bound chosen for browser robustness; it is not presented as a universal constitutive-law restriction.

13 · Standard compressibility

Volumetric terms and free transverse deformation

D1 family

Neo-Hookean, Mooney-Rivlin, Ogden, Yeoh and Reduced Polynomial use:

Uvol = (J−1)²/D₁ = 1/2 K₀(J−1)²,   K₀ = 2/D₁.

With pressure positive in compression:

p = K₀(1−J).

D family

Arruda-Boyce and Van der Waals use:

Uvol = (1/D)[(J²−1)/2 − ln J] = 1/2 K₀[(J²−1)/2 − ln J],   K₀ = 2/D.
p = 1/2 K₀(1/J − J).

Normal loading

The tool does not prescribe a lateral Poisson ratio for these finite-strain compressible laws. Instead, it solves the free transverse stretch by minimizing total energy for each prescribed axial stretch.

Simple shear

Ideal simple shear has J = 1, so the volumetric term contributes zero energy and zero pressure.

14 · Compressible foam model

Ogden Hyperfoam, N = 1

Hyperfoam is treated separately from “compressible Ogden + D1.” It is inherently compressible and couples distortional and volumetric behavior in the same potential.

U = (2μ/α²)[λ₁^α + λ₂^α + λ₃^α − 3 + (1/β)(J^(−αβ) − 1)].
β = ν/(1−2ν).

When |β| < 10−9, the code evaluates the analytic limit of the volumetric term:

(J^(−αβ)−1)/β → −α ln J.

Principal nominal stress

τj = (2μ/α)[λj^α − J^(−αβ)] Pj = τj/λj Pj = (2μ/α)[λj^(α−1) − J^(−αβ)/λj].

Uniaxial free-surface derivation

Let λ2 = λ3 = t. Zero transverse stress: t^α = J^(−αβ) t = J^(−β) J = λ t² t = (λ t²)^(−β) t^(1+2β) = λ^(−β) t = λ^[−β/(1+2β)] Since β = ν/(1−2ν): β/(1+2β) = ν Therefore: λ2 = λ3 = λ^(−ν).

Equibiaxial and planar free surfaces

Equibiaxial: λ₁ = λ₂ = λ,   λ₃ = λ−2ν/(1−ν)
Planar: λ₁ = λ, λ₂ = 1,   λ₃ = λ−ν/(1−ν).

Volumetric pressure

p = (2μ/α)[J−αβ−1 − Jα/3−1].

Simple shear

η = asinh(γ/2)
W = (4μ/α²)[cosh(αη)−1]
τ = (4μ/α)sinh(αη)/sqrt(4+γ²).

Initial moduli

G₀ = μ,   K₀ = 2μ(β + 1/3).

The Hyperfoam implementation is restricted to N = 1 in v1.0.

16 · Objective functions

Abaqus relative error, least squares and reporting metrics

Abaqus relative stress-error objective

Erel = Σ[1 − Tmodel,i/Ttest,i]².

This is equivalent to weighted least squares with

wᵢ = 1/Ttest,i².

Experimental points with |Ttest| ≤ 10−12 are omitted from the relative objective because the denominator is undefined. They remain in RMSE and R² reporting.

Absolute least squares

Eabs = Σ(Tmodel,i − Ttest,i)².

Reported metrics

SSE = Σ(Ttest,i−Tmodel,i)²
RMSE = sqrt(SSE/n)
R² = 1 − SSE/SST.

The selected objective is what determines the fitted parameters. RMSE and R² are reporting metrics and can rank candidates differently from the relative-error objective.

17 · Optimization

Direct weighted linear least squares

When stress is linear in the unknown coefficients, the tool avoids iterative optimization. For

Tmodel,k = Σ cⱼ qⱼ(xₖ)

the weighted normal equations are

(QᵀWQ)c = QᵀWy.

The browser assembles these matrices directly and solves them with Gauss-Jordan elimination and partial pivoting. A pivot magnitude below 10−18 is treated as singular.

Single-coefficient case

c = [Σw q y]/[Σw q²].
Model / quantityUnknowns solved directly
Linear referenceE
Neo-Hookeanμ
Mooney-RivlinC10, C01
YeohC10, C20, C30
Reduced Polynomial N=2C10, C20
Volumetric D / D1 familyK0, then D or D1 = 2/K0

Mooney-Rivlin basis

Uniaxial: q10 = 2(λ−λ^−2) q01 = 2(1−λ^−3) Equibiaxial: q10 = 2(λ−λ^−5) q01 = 2(λ³−λ^−3) Planar: q10 = q01 = 2(λ−λ^−3) Simple shear: q10 = q01 = 2γ.

Yeoh basis

P = 2A C10 + 4XA C20 + 6X²A C30 Therefore: q10 = 2A q20 = 4XA q30 = 6X²A.

No positivity constraint is imposed on Mooney-Rivlin, Yeoh or Reduced Polynomial coefficients by the linear solver. This allows mathematically best fits but places responsibility on the user to check physical admissibility and stability.

18 · Optimization

Profile searches and nonlinear simplex optimization

The implementation reduces nonlinear dimension wherever possible by solving any linear scale parameter analytically inside the nonlinear search.

Ogden N=1

  1. Choose a trial α.
  2. At fixed α, stress is linear in μ; solve μ by weighted single-coefficient least squares.
  3. Reject μ ≤ 0.
  4. Coarse deterministic scan α from −12 to −0.2 and +0.2 to +12 in increments of 0.08.
  5. Refine around the best α over ±0.20 with step 0.004.
  6. Reject |α| < 0.15.

This is a deterministic profile search. It is not the internal Abaqus optimizer.

Arruda-Boyce

  1. Choose a trial λm.
  2. Set μ = 1 and calculate the unit response.
  3. Because stress scales linearly with μ, solve μ analytically by weighted least squares.
  4. Reject μ ≤ 0.
  5. Search 151 logarithmically spaced λm values from 1.05 to 25.
  6. Refine around the best ln(λm) with 161 points at log-space increment 0.0015.

Van der Waals / Kilian

For fixed λm, a and β, stress is linear in μ. The tool profiles μ analytically and searches only the remaining nonlinear parameters.

λm = √3 + exp(z₀)
a = 0.95 tanh(z₁)
β = logistic(z₂), if β is fitted.

Multi-start seeds:

λm seeds = [2.2, 3.2, 5, 7, 12] a seeds = [−0.25, 0.10, 0.40] β seeds = [0.03, 0.25, 0.60] when β is fitted At most 24 generated combinations are retained. The current UI state is also inserted as an additional start.

Simplex step sizes are [0.28, 0.35] when β is fixed and [0.28, 0.35, 0.65] when β is fitted. Each run is limited to 110 iterations.

Hyperfoam N=1

For fixed α and ν, the response is linear in μ. The tool solves μ analytically and performs a nonlinear search only in α and optionally ν.

|α| = 0.15 + exp(z₀), with sign inherited from the seed
ν = −0.95 + 1.44 logistic(z₁), if ν is fitted.
α seeds = [−8, −4, −2, 2, 4, 8] ν seeds = [−0.10, 0.05, 0.20, 0.35, 0.45] when fitted Simplex step sizes: [0.32] for fixed ν [0.32, 0.55] when ν is fitted Maximum iterations per start = 120.

Custom Nelder-Mead-style simplex

The implementation uses a compact deterministic simplex routine with:

reflection = 1, expansion = 2, inward contraction = 0.5, shrink = 0.5.

At each iteration, vertices are sorted by objective. The worst point is reflected through the centroid. If reflection improves on the best point, an expansion is tried. If reflection is not accepted, an inward contraction is attempted; otherwise the simplex is shrunk toward the best vertex.

Early termination occurs when

max(f) − min(f) < 10−11 max(1, |fbest|).

Important distinction: this is a MakeCoTech browser optimization strategy chosen for transparency and robustness. It is not claimed to duplicate Abaqus' proprietary internal numerical optimizer.

19 · Numerical evaluation

Transverse minimization, finite differences and safeguards

Golden-section minimization for standard compressible models

The initial estimate for the free transverse stretch is the corresponding incompressible value:

Uniaxial: t₀ = λ−1/2
Equibiaxial: t₀ = λ−2
Planar: t₀ = λ−1.

The one-dimensional search interval is

a = max(10−5, 0.12 t₀)
b = min(50, max(6 t₀, 0.2)).

The tool then executes 82 golden-section iterations using φ = (√5−1)/2 and returns the midpoint of the final bracket.

Numerical stress differentiation

For generic incompressible normal-response models:

h = max(10−6, |λ|·2×10−5).

For standard compressible normal response, each λ±h state is independently re-minimized in the transverse direction before the energy derivative is taken:

h = max(2×10−6, |λ|·10−5).

This re-equilibration at both derivative points is important for accuracy at large K0.

For generic simple shear:

h = max(10−6, |γ|·2×10−5 + 10−6).

Biaxial factor

Because differentiating the path energy with respect to the common biaxial λ produces P1+P2, the tool multiplies the path derivative by 1/2 to report the nominal stress in one loaded direction.

Numerical barriers

  • J must remain positive.
  • Invalid high-energy states return a large penalty value.
  • Van der Waals rejects η ≥ 0.999999.
  • Van der Waals clips Ĩ−3 to zero before square-root / 3/2 operations.
  • General UI stretch/volume ranges must remain positive.
  • Normal/volumetric range magnitudes are limited to 25 by the GUI safety check.
  • Simple-shear range magnitude is limited to 50.
  • Non-finite optimization values are replaced with a large penalty.
20 · Convenience operation

“Match Initial Stiffness” logic

This button is not a fitting routine. It updates model parameters so that the initial small-strain stiffness is approximately consistent with the user-entered reference E.

Incompressible

G = E/3.

Compressible standard models

Using

E = 9K₀G/(3K₀+G),

the tool solves

G = 3EK₀/(9K₀−E).

If 9K0 ≤ E, the match is rejected as incompatible with the intended positive isotropic moduli.

Parameter assignment

ModelAssigned initial-stiffness parameter
Neo-Hookeanμ = G
Ogden N=1μ = G
Mooney-RivlinC10+C01 = G/2, split 70% / 30%
YeohC10 = G/2; higher-order coefficients are not reset
Reduced PolynomialC10 = G/2; C20 is not reset
Arruda-Boyceμ = G / Arruda correction factor
Van der Waalsμ = G
Hyperfoam N=1μ = E/[2(1+ν)] using the current Hyperfoam ν

The 70/30 Mooney-Rivlin split is only a convenient initialization preserving the correct initial shear modulus. It is not a material identification result.

21 · Verification data

Built-in Abaqus benchmark presets

Abaqus SI Hypertest Benchmark

The preset contains 23 uniaxial, 16 equibiaxial, 13 planar and 4 volumetric points. The tool stores/displays stress in MPa and selects compressible behavior plus the Abaqus relative-stress objective. The preset is intended to exercise both the deviatoric and volumetric fitting workflow.

Abaqus 2016 Rubber-Fit Benchmark

The second preset stores the older Treloar fitting data in their raw kgf/cm² stress and nominal-strain form, then converts them at load time:

λ = 1 + εnominal
1 kgf/cm² = 0.0981 MPa.

It includes 23 uniaxial, 16 biaxial and 13 planar points, uses incompressible fitting and selects the relative-stress objective.

The 2016 Abaqus benchmark documentation reports an all-data Arruda-Boyce fit near

μ = 3.28 kgf/cm² ≈ 0.3218 MPa,   λm = 5.24.

This published result is useful as an external coefficient-level cross-check.

23 · Limitations

Stability, extrapolation and responsibility

The tool reports fit error and allows visual extrapolation, but it does not perform a complete constitutive stability assessment such as the full Abaqus Drucker stability check or a general strong-ellipticity analysis.

A fitted coefficient set may:

  • match the supplied data but be non-unique;
  • be poorly conditioned because the chosen loading modes do not identify every coefficient;
  • behave unrealistically outside the calibration range;
  • be numerically unstable in a finite-element model;
  • fail to represent temperature, rate, damage or cyclic effects present in the real material;
  • be unsuitable for another stress state despite a high R² value.

Educational and preliminary engineering use only. The user is responsible for independent validation of experimental data, units, coefficients, extrapolation, material stability and the final finite-element implementation. MakeCoTech provides no warranty that a fitted law is suitable for a particular component, design decision or safety-critical application.

24 · Reproducibility

Checklist for reproducing a tool result

A calibration report should record at minimum:

  • Tool name: MakeCoTech Hyperelastic Explorer
  • Tool version: 1.0
  • Selected constitutive law
  • Incompressible / compressible behavior
  • D or D1 family where applicable
  • All entered model parameters
  • Hyperfoam ν handling or Van der Waals β handling
  • Selected fitting objective
  • Which loading-mode checkboxes were enabled
  • Input strain definition for each dataset
  • Input stress definition for each dataset
  • Fit Min / Max and whether restriction was active
  • Experimental units and any conversions
  • RMSE and R²
  • Fitted coefficient set
  • Calibration range and intended FEA range

The Excel export is designed to preserve most of this information together with generated curves and experimental data.
