Getting Started

Quick Start

1

Choose a loading mode

Select Uniaxial, Equibiaxial, Planar / Pure Shear, Simple Shear or Volumetric loading.

2

Choose a material model

Select the constitutive law to inspect or fit. The selected model is highlighted in the live charts.

3

Enter experimental data

Select the deformation and stress definitions, then paste two columns directly from Excel into the 30-row table.

4

Select the datasets used for fitting

The dataset selector chooses which table is visible. The checkboxes decide which test modes participate in the combined calibration.

5

Choose the fitting objective

Use Abaqus relative stress error for Abaqus-style comparison, or Standard least squares / RMSE when absolute stress error is preferred.

6

Fit and inspect the response

Use Fit Selected Model or Fit All Models, then inspect the curves, metrics and extrapolated behavior before transferring coefficients to FEA.

Display & Calibration Window

Display range versus fit range

Display Min / Max controls the chart domain, deformation slider and generated curve range.

Fit Min / Max controls which experimental points can participate in calibration when “Restrict fit” is enabled.

Use Experimental Range automatically uses the minimum and maximum of the active dataset. The range settings are stored independently for each loading mode.

This separation is intentional: you can calibrate only over a trusted experimental interval while still displaying the model outside that range to inspect extrapolation.

Experimental Input

Entering experimental data

The tool supports up to 30 points per loading mode and accepts direct two-column paste from Excel.

ModeDeformation inputStress input
Uniaxial / Biaxial / PlanarStretch λ or engineering strain %Nominal / engineering stress; Cauchy stress is available for incompressible behavior
Simple shearγ or engineering shear %Shear stress τ
VolumetricVolume ratio J or volume change %Compression pressure p

For compressible normal loading, the tool requires nominal / engineering stress because converting Cauchy stress to nominal stress requires additional lateral-deformation or volume information.

Calibration

Fitting the material parameters

Fit Selected Model calibrates the currently selected constitutive law. Fit All Models fits the implemented models to the same selected datasets for comparison.

Abaqus relative stress error

This objective emphasizes relative stress error and is intended for comparison with Abaqus-style hyperelastic calibration.

Standard least squares / RMSE

This objective minimizes absolute stress residuals and may be more appropriate when absolute error across the measured stress range is the engineering priority.

A low fitting error does not prove parameter uniqueness, physical stability or reliable extrapolation. Always inspect the material response outside the calibration points.

Verification Presets

What is the difference between the two Abaqus benchmark buttons?

Abaqus SI Hypertest Benchmark

Loads 23 uniaxial, 16 biaxial, 13 planar and 4 volumetric points. The source data are SI-based and the tool displays stress in MPa. Compressible behavior and volumetric fitting are enabled.

Abaqus 2016 Rubber-Fit Benchmark

Loads the raw Treloar values from the older fitting example. Nominal strain is converted with λ = 1 + ε and stress with 1 kgf/cm² = 0.0981 MPa. Only uniaxial, biaxial and planar data are used, and the example is treated as incompressible.

The 2016 guide reports an all-data Arruda–Boyce result near μ = 3.28 kgf/cm² (about 0.3218 MPa) and λm = 5.24, providing a useful published cross-check.

Educational and preliminary engineering use

This tool does not replace material testing, constitutive-model verification or solver-level validation. The user remains responsible for checking units, experimental definitions, parameter identifiability, extrapolation, stability and the final FEA implementation.
